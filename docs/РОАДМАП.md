# Роадмап семейного бота

Единый список работ. Общие правила для всего: **по `guild_id`**, каждый блок — **модуль-тумблер** (`/настройки` + шаг мастера), управление **речью + кнопками панели** (не командами), существующее **не ломать**, суммы — внутриигровые вирты (не реал).

## Порядок (фазы)
0. ✅ GitHub + `/обновить`.
1. **Упрощение UX + гранулярные настройки** — см. `КАРТА_УПРОЩЕНИЯ_КОМАНД.md` (`/помощь`, мастер `/настройка`, панели, скрыть лишнее) + настройки до уровня отдельных действий (ниже).
2. **Экономика** — казна → зарплаты → штрафы.
3. **Кадры** — авто-испытательный, статистика рекрутёров, контроль ника.
4. **ИИ/автоматизация** — интернет-поиск, сторож, «что я пропустил», черновики, join-to-create, отложенные анонсы.
5. **Прочее** — автопарк; на будущее: ивенты-планировщик, уровни, магазин.
6. **Сайт** (позже, на общей базе Postgres).

## Гранулярные настройки (фаза 1, сквозной принцип)
Настройки — не только модуль вкл/выкл, а **дерево**: модуль → его отдельные действия/под-фичи, с частичным включением. Примеры:
- Персона: визиты · подколы · приветствия · память — каждое отдельно.
- Казна: взносы · зарплаты · штрафы — отдельно.
- Модерация: анти-спам · чужие инвайты · реал-деньги · авто-наказания — отдельно.
- Кадры: экзамен-фильтр · авто-перевод · контроль ника — отдельно.
Хранить как `gset(guild, "mod:<модуль>:<действие>", on/off)`. Мастер и `/настройки` показывают дерево с галочками. Код каждой фичи проверяет свой флаг. Любой, кто добавил бота, настраивает детально под себя.

## Фаза 2 — Экономика

### Казна — см. `СПЕЦ_КАЗНА.md`
База всего экономического блока. Роль 💰 Казначей, доступ `TREASURY = LEAD + ["treasurer","senior"]`.

### Зарплаты / выплаты из казны
- Начисление: **по рангам** (ставка на роль), **за ивенты**, **за рекрутёрство** (из статистики ниже), разовые.
- Настройка ставок: `gset(guild,"salary:<role>", сумма)`. Выплата = `treasury_tx kind='out', reason='зарплата: …'`, в ЛС получателю уведомление.
- Речь: «выплати организаторам по 50к», «начисли зарплаты по рангам», «заплати рекрутёрам за неделю».
- Кнопки: Казна → Зарплаты (ставки · выплатить всем · за ивент · рекрутёрам).
- Защита: суммарная выплата больше баланса — подтверждение; только `TREASURY`.

### Штрафы
- Назначить участнику: сумма + причина. Таблица `fines(id, guild_id, user_id, amount, reason, paid INTEGER, ts)`.
- **Напоминания**: раз в день бот пишет должникам в ЛС (и/или пинг в hr-канале) о непогашенных штрафах.
- Оплата штрафа → в казну (`treasury_tx kind='in', reason='штраф'`), `fines.paid=1`.
- Связка с выговором: при выговоре можно сразу назначить штраф.
- Речь: «штраф Пете 30к за опоздание», «кто со штрафами?», «Петя оплатил штраф».
- Кнопки: Казна/Модерация → Штрафы (назначить · список должников · отметить оплату).

## Фаза 3 — Кадры

### Экзамен-фильтр + ручное принятие
- Не сдал экзамен → бот **не допускает** (авто-перевод не срабатывает, статус «не сдал»).
- **Всегда есть ручной обход:** руководство/кадровик кнопкой «Принять вручную» или речью «прими Петю в семью» — заводит человека по своему усмотрению, минуя экзамен. Логировать, кто принял вручную.
- Экзамен-фильтр — отдельный тумблер (семья может вообще не требовать экзамен).

### Авто-испытательный срок
- Новичок получает роль `newbie` → старт срока (сохранить ts).
- Через `probation:days` (по умолчанию 7) **и** сданный экзамен → бот **авто-переводит** в `member` (или, если `probation:mode='propose'` — предлагает кадровику кнопкой).
- По ходу срока — напоминания наставнику/кадровику.
- Настройки: длительность, авто/предложение, нужен ли экзамен.

### Статистика рекрутёров (под зарплату)
- На каждом решении по заявке писать: `reviewer_id`, исход (`обзвон`/`принят`/`отклонён`), `ts`. (расширить applications/interviews).
- Отчёт **за выбираемый период** (неделя/месяц/произвольно): по рекрутёру — обзвонов, принято, отклонено.
- Кнопки: Заявки → Статистика рекрутёров (период). Речь: «статистика рекрутёров за неделю».
- Связь с зарплатой: платить за принятого/за обзвон (ставка настраивается).

### Контроль ника
- Формат-шаблон в настройках (например `Имя Фамилия [ID]`), регэксп на сервер.
- Проверка: периодически + при смене ника. Несоответствие → **ЛС с просьбой** поправить; бот **принимает ответ в ЛС** (новый ник) и ставит его сам (через модалку или текст-ответ).
- Исключения: админ/владелец, боты. Логировать правки.

## Фаза 4 — ИИ / автоматизация

### Интернет-поиск
- Бесплатный поиск (DuckDuckGo-подобный), работает на хосте. Бот отвечает на актуальное/факты.
- Шутки/анекдоты ИИ может и сам (без поиска) — добавить действие «расскажи анекдот/шутку».
- Действие ИИ `web_search {query}` → краткая выжимка в ответ.

### Сторож (watchdog)
- Если ИИ/войс/Whisper падают дольше 10 мин — ЛС Главе. Статус также в `/помощь` и `/статус`.

### «Что я пропустил»
- ИИ-сводка активности канала/семьи за время отсутствия (по времени последнего захода или за N часов).

### Черновики (ИИ-драфты)
- Анонсы, описания ивентов, пиар-посты. Расширить существующий ИИ-юрист (он уже делает документы).

### Join-to-create voice
- Спец-канал «➕ Создать комнату»: зашёл → бот создаёт личную комнату и переносит; пустая — удаляется. (переиспользовать модуль комнат.)

### Отложенные анонсы
- Запланировать объявление на дату/время → бот опубликует сам. Хранить задания по `guild_id`.

### Ретранслятор новостей (внешние анонсы → переформат)
- Источник официальных анонсов/чек-логов (например Majestic/игры): либо бот состоит в том сервере и читает канал анонсов, либо (чище, без вступления) семья **подписывает** его announcement-канал в свой стейджинг-канал через Discord «Follow», а бот слушает стейджинг.
- Новый пост → ИИ **вытаскивает полезное и переформатирует** в стиль семьи (убирает воду, оставляет суть: что изменилось/важные даты) → публикует в канал новостей.
- Настройка: источник(и), целевой канал, фильтр (ключевые слова/темы), дедуп, вкл/выкл. Можно режим «черновик на подтверждение» перед публикацией.

## Фаза 5 — Прочее

### Лог автопарка
- Реестр машин семьи: владелец/пользователь, модель, номер, заметка, статус. Таблица `vehicles(id, guild_id, user_id, model, plate, note, status, ts)` + лог изменений.
- Кнопки: Автопарк → список · добавить · передать · снять. Речь: «запиши машину Elegy у Пети, номер А123», «чьи машины?».
- (опц.) отдельный лог-канал автопарка.

### На будущее
