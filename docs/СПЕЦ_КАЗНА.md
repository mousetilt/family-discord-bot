# Спецификация: Казна семьи (модуль `treasury`)

Внутриигровые вирты семьи. Баланс + членские взносы (кто сдал / кто должен). Включается в `/настройки`.
Всё по `guild_id`. Действия — через речь (ИИ) и кнопки панели, в духе упрощения.

## Роль и доступ
- Новая должность **💰 Казначей** (`treasurer`): добавить в `config.ROLES`, `STAFF_POSTS`, `FAMILY_RANKS`, `ROSTER_ORDER` (рядом с hr_head/recruiter).
- Константа доступа: `TREASURY = LEAD + ["treasurer", "senior"]` (Глава, зам, совет, казначей, старший состав).
- **Вести и видеть казну** могут только из `TREASURY`. Обычные участники — нет (можно потом смягчить настройкой).

## Данные (таблицы с `guild_id`, схема v3, миграция как делали)
```sql
treasury_tx(
  id INTEGER PRIMARY KEY, guild_id INTEGER, user_id INTEGER,
  amount INTEGER,            -- всегда > 0
  kind TEXT,                 -- 'in' приход | 'out' расход | 'due' членский взнос
  reason TEXT, ts INTEGER
)
```
- **Баланс** = `SUM(amount WHERE kind IN ('in','due')) - SUM(amount WHERE kind='out')`.
- Настройки взносов в `guild_settings`: `dues:amount` (сумма с человека), `dues:period` (`week`|`month`), `dues:since` (старт текущего периода, ts).
- **Кто сдал / кто должен** за текущий период: взял `family_members(guild)`; сдал = у кого сумма `kind='due'` за период (ts ≥ начало периода) ≥ `dues:amount`; остальные — должники (с учётом частичной оплаты показывать «сдал X из Y»). Освобождённые от взносов: `vacation`, `newbie` (на испытательном) — не считать должниками.

## Разбор и формат сумм
- `parse_amount("50к")→50000`, `"1.2кк"/"лям"/"2м"→1_200_000/…`: суффиксы `к`=1e3, `кк`/`лям`/`м`=1e6, `ккк`/`млрд`=1e9. Без суффикса — число как есть. Отбрасывать пробелы/разделители.
- Вывод: `f"{n:,}".replace(",", " ")` → `1 200 000` вирт.

## Действия через речь (новые ИИ-actions в assistant.py)
- `treasury_in {amount, from_user?, reason}` — «внеси в казну 50к от Пети за сделку»
- `treasury_out {amount, reason}` — «расход 20к на тачку» (если > баланса — предупредить, не уводить в минус без подтверждения)
- `treasury_due {amount, user}` — «Петя сдал взнос» / «запиши взнос 100к с Саши»
- `treasury_balance` — «сколько в казне?»
- `treasury_debtors` — «кто не сдал взнос?»
- `dues_set {amount, period}` — «взнос 100к в неделю» (только Глава/зам)
Все — только для `TREASURY`, иначе отказ «не твоя забота».

## Панель «Казна» (кнопки, без команд)
Кнопка в Панели руководства → под-меню:
`💰 Баланс` · `➕ Внести` · `➖ Расход` · `✅ Взнос сдан` · `📋 Кто должен` · `🧾 История` · `📊 Отчёт` · `⚙️ Настроить взнос`
- Внести/Расход/Взнос — модалки (сумма, за что, участник).
- История — последние 15 операций с автором и временем.
- Отчёт — баланс, приход/расход за период, топ-вкладчики, число должников.

## Команды (минимум; видны только `TREASURY`)
- (опц.) группа `/казна баланс | внести | расход | должники` как ярлык. Можно не делать — хватит речи+панели.

## Логи и интеграции
- Новый ключ канала `ch:treasury_log` (или переиспользовать `hrlog`): каждая операция пишется туда — кто, сколько, тип, за что.
- В `сводку` и ежедневный дайджест добавить строку: `💰 Казна: <баланс> · должников: <N>`.
- Модуль `treasury` в список тумблеров `/настройки` и шаг «Модули» мастера. По умолчанию — выключен (семья включает).

## Крайние случаи
- Расход больше баланса → предупредить, требовать подтверждение (не уводить в минус молча).
- Суммы — целые, > 0; отрицательные/ноль/мусор → понятная ошибка.
- Смена `dues:amount`/`period` не трогает прошлые периоды.
- Участник ушёл из семьи → в должниках не числится (считаем по текущему составу).
- Всё фильтровать по `guild_id`.
