# Ревизия 3 — «работает идеально», мультисемейность, простота управления

Дата: 2026.11.23 · версия кода 2026.11.23.3 · ≈25,5 тыс. строк (39 когов, 21 модуль core) · тесты: 135 + новый test_voice — все зелёные.

Метод: ядро (`core/botcore, db, config, family, ai, agent, brief, vision, kb, legal, forum, people, secret, insights`) и
`cogs/assistant.py` прочитаны целиком; `families, control, daily, maintenance, errorwatch, security, export` и ключевые
места `forumwatch, hub, treasury, persona, jarvis` — построчно в части прав, данных и сети. По ВСЕМУ коду прогнаны
автоматические проверки: ответ Discord после долгой работы (10062), модалки >5 полей, SQL по таблицам семьи без
`guild_id`, глобальные настройки без `guild_id`, фоновые циклы без защиты, дубли/лимит слэш-команд, сверка
«действия в промпте ↔ PERMS ↔ LABEL ↔ обработчики», голые `except`, незакрытые сессии, `create_task` без ссылки.
Вызовы Claude сверены с актуальной справкой API.

## Общая оценка

Код в хорошем состоянии: данные семьи везде по `guild_id`, права проверяются перед изменяющими действиями, ИИ-слой с
фолбэком и лимитами, секреты зашифрованы и вырезаются из копий, фоновые задачи под `guarded`, промпт помощника и его
обработчики сходятся (рассинхрона действий нет). Ошибки, найденные в этот раз, — точечные: **одна поломка, видимая
пользователю** (модалка «Числа → Дисциплина»), **одна латентная дыра маршрутизации** (не сохраняется домашний сервер),
несколько мест **прав в войсе**, **стоимости Claude** и **гигиены секретов в копиях**. Главный долг для массового
подключения — **проектная привязка форума/юриста к серверу «Арбатский»** и **20 свободных слотов слэш-команд из 100**.

## 2. Коллизии и мультисемейность

### Что уже хорошо
Все таблицы семьи с `guild_id`; настройки — `guild_settings`; ИИ чужих семей только на их ключах; копия чужой семье —
только её данные; альянс и подключённые семьи разведены (`dispatch`, `FamilyTree`); одобрение новых семей.

### Что мешает «пригласил — и работает» (с доработками)
1. **Домашний сервер в базе** (🔴 выше) — без этого массовое подключение опасно.
2. **Профиль по умолчанию — имя сервера**, а не «Ульяновы» (🟡 выше).
3. **Форум и юрист привязаны к «Арбатскому»**: `core/forum.SECTIONS` (id разделов жалоб/судов), `LAW_SECTIONS`
   (1471/1474), `legal.SECTION_TEMPLATE`, `kb.LAWS_SECTION`, `config.PROJECT_RULE_URLS`, `HEAD_TITLES`.
   **Доработка:** «пресет игрового сервера» — таблица `forum_presets` (сервер → разделы, законы, формы), выбор в
   мастере по полю «Игровой сервер» профиля; для неизвестного сервера — модуль форума предлагает вставить ссылки на
   разделы (модалка), id вытаскиваются из ссылок сами. Общая база правил проекта (`guild_id=0`) остаётся общей.
4. **Модули с данными «Ульяновых»** (`forumwatch.KNOWN_CASES/PEOPLE`) — только домашнему, уже так; вынести в
   `data/seed_home.json`, чтобы в коде не было фамилий.
5. **Общие ресурсы:** один SQLite-коннект — при 5–10 активных семьях понадобится `busy_timeout` и (позже) пул/aiosqlite;
   один бот-голос на сервер — ок (`hold`), но **Whisper и ИИ хоста не делятся** (верно); дневной лимит Whisper — по
   серверу ✔.
6. **Слэш-команды** — 80/100 (🟡 выше): у каждой подключённой семьи тот же набор, места под новое почти нет.

### Новые функции под массовое подключение
- **`/семья проверка` (самодиагностика одним экраном)** — для владельца чужого сервера: ✅/⚠️/❌ по пунктам —
  права бота (админ/управление ролями/каналами/вебхуками), роль бота выше ролей семьи, интенты (members, message
  content, presences), привязаны ли 12 ролей и ключевые каналы, дубли ролей/каналов по названию, ключ ИИ
  (провайдер, лимит сегодня), Whisper, модули вкл/выкл, профиль заполнен, одобрение. У каждого ❌ — кнопка «Исправить»
  (открывает нужный шаг мастера). Основа уже есть: `server_setup.audit` + `families.suggestions`.
- **Мастер при входе с автоподстройкой**: на `on_guild_join` сразу снимок сервера — какие роли/каналы похожи на
  наши (`suggestions` + такая же карта для каналов), и в приветствии: «Нашёл 9 ролей и 14 каналов — привязать?»
  кнопкой «Применить всё» → потом мастер только добивает недостающее.
- **Гранулярные права бота при приглашении** вместо `permissions=8` (админ) — и подсказка, какое право за что.
- **Перенос/миграция настроек:** «📦 Экспорт настроек» (роли/каналы по названиям, модули, числа, тексты) → JSON-файл;
  «Импорт» на другом сервере с сопоставлением по названиям. Пригодится при переезде семьи и как шаблон «как у
  Ульяновых» для новых.
- **Шаблоны из коробки:** 2–3 пресета модулей («минимум: заявки+выговоры», «стандарт», «всё») — одна кнопка в мастере.
- **Разделение «общее ↔ семья»** в `/статус` и `/семья проверка`: что задаёт хост (бот, голос TTS по умолчанию,
  общая база правил проекта) и что — семья.

## 3. Простота управления

**Сейчас:** 55 команд + 27 групп = 80 корней, 178 подкоманд; плюс речь (≈70 действий) и панели. Рядовым многое
скрыто (`HIDDEN_FOR_MEMBERS`), но руководству в `/` по-прежнему видны десятки корней.

### Свести и скрыть
- В группы: `/отпуск`+`/вернулся` → `/отпуск`; `/топ`, `/профиль`, `/выговоры`, `/кто` → под `/семья …` или только
  панель+речь; `/статус`, `/перезапуск`, `/обновить`, `/модуль`, `/разработчик` → `/бот …` (одна группа служебного);
  `/черновик`, `/запланировать`, `/запланированные`, `/поиск`, `/пропустил` → `/помощник …`. Освобождает ~12 корней.
- Всё, что есть в панели или речи, — скрыть у рядовых и у руководства без нужды (`default_permissions`).

### Новые функции простоты
- **Единый мастер `/настройка`** — добавить шаги, которые сейчас отдельными командами: «Голос и Whisper»
  (`/голос`), «Форум» (`/форум вход/интервал/исключения`), «Казна» (взнос, ставки), «Наставники» (срок),
  «Ник-контроль» (шаблон), «Разработчик» (только домашний). В конце — экран «Готово: что работает / что выключено».
- **«Здоровье бота» одним экраном** (кнопка в `/панель` и `/статус`): ИИ (провайдер, ✔/лежит с …, лимит сегодня,
  Claude — сколько вызовов), голос (готов/занят), Whisper (сегодня N/1800), форум (последняя проверка, ошибка входа),
  хостинг (до отключения), последние 3 ошибки — человеческим языком.
- **Интерактивная `/помощь`**: выбор роли («я рядовой / рекрутёр / Глава») → 5–7 главных фраз Швейцару и кнопок
  панели для этой роли; кнопка «Попробовать» отправляет пример фразы.
- **Человеческие ошибки-подсказки**: единый `explain(error)` — Forbidden → «перетащи роль бота выше {роль}»;
  нет канала → «включи модуль/привяжи канал в мастере [кнопка]»; нет ключа ИИ → кнопка `/ии ключ`.
- **Онбординг руководства**: новому Главе/заму при выдаче роли — ЛС «3 вещи, которые стоит знать» + ссылка на
  панель; раз в неделю — «совет недели» (фича, которой семья не пользуется) в бот-команды, тумблером.
- **Кнопка «Что я могу?»** под любым ответом «не по чину» — список того, что этому человеку доступно.
