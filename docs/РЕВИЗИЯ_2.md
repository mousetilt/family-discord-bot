Версия кода: **2026.11.17.10** (после правок ревизии 1: защита по серверам, права на ранги, таймаут gTTS).
Прочитано: `core/*` и все 37 файлов `cogs/` целиком, `bot.py`, `launcher.py`, `docs/РОАДМАП.md`, `docs/КАРТА_УПРОЩЕНИЯ_КОМАНД.md`.
Автопроверки: офлайн-загрузка всех когов, сверка ИИ-действий (`PERMS`/`LABEL`/`SAFE`/промпт ↔ обработчики), дубли
слэш-команд, кнопки панелей ↔ скрытые команды, SQL без `guild_id`, глобальные ключи `settings`, какие команды видит рядовой.

Обозначения: 🔴 — вредит людям или ломает обещание бота; 🟡 — заметный баг или коллизия; 🟢 — мелочь.
«(Р1)» — найдено ещё в ревизии 1 и пока не исправлено.

## Коротко

Код аккуратный и единообразный: защитный стиль, `guarded` у циклов, `outranks` у наказаний, почти идеальная
дисциплина `guild_id` в SQL. Действия ИИ согласованы с обработкой (мёртвых веток нет), дублей команд нет (81 из 100).

Главное, что нашлось в этот раз:
1. 🔴 **Анонимные обращения не анонимны**: ID автора лежит в ежедневной копии базы, которая уходит владельцу сервера
   (обычно это и есть Глава).
2. 🟡 **Ког `banner` не загружается вообще** (его нет в `config.EXTENSIONS`), а тумблер «Авто-баннер» в `/настройки` есть.
3. 🟡 **Обходы проверок**: кнопки ИИ-модерации дают выговор/мут без иерархии; кнопка «Перевести» в ветке наставника
   повышает новичка без экзамена; авто-перевод не видит выговоры, которые успели «сгореть» за срок.
4. 🟡 **Джарвис распознаёт речь всех в канале**, а не только тех, кто командует: тратит лимит Whisper (18/мин) и
   отправляет в Groq разговоры людей, которые бота не звали.
5. 🟡 Мастер `/настройка` на готовом сервере переставляет **всю** иерархию ролей и меняет чужие настройки сервера.
6. Остаток ревизии 1 (коллизии по серверам в активности, составе, ИИ-модерации и т.д.) — см. таблицу.

## По блокам

### 1. Заявки, собеседования, экзамен (`applications`, `interviews`)
**Статус:** работает, логика продумана (ЧС на входе, задержки повтора, ручной приём, закрытие карточек).
**Баги:**
- 🟢 `applications.py:519-526` — двое одновременно жмут «Принять»: статус меняется после `defer`, оба проходят →
  двойной приём и два приветствия. (Р1)
- 🟢 `applications.py:272` — сессия экзамена по `user_id`: заявки в две семьи одновременно перетирают друг друга. (Р1)
- 🟢 `applications.py:561` — картинка-приветствие (PIL) рисуется в цикле событий. (Р1)
- 🟢 Брошенные анкеты в статусе `exam` (закрыл окно теста) висят вечно — их видно только как «abandoned» при новой подаче.
**Коллизии:** нет — всё по `guild_id`.
**Идеи:**
- Кнопка «📄 Где моя заявка?» на панели заявок: статус, кто взял, сколько ждать — меньше вопросов в ЛС.
- Напоминание отделу кадров, если новая заявка не взята 2 часа (пинг в `hr_chat`, раз в заявку).
- В очереди ожидания собеседования — номер в очереди голосом («перед вами 1 человек»).
- Ник после приёма бот ставит как `Ник [Static]` — если включён контроль ника, брать **шаблон семьи** (сейчас
  формат зашит, и новичок сразу получает ЛС «поправь ник»).

### 2. Кадры (`staff`, `recruit`, `mentorship`, `nickcheck`, `context_menus`)
**Статус:** ранги/должности/выговоры через слэш и меню — с иерархией. После ревизии 1 закрыты «себе ранг» и речь.
**Баги:**
- 🟡 `mentorship.py:147` — кнопка «Перевести в Члены семьи» появляется, когда чек-лист отмечен, и **повышает без
  экзамена** при включённом `hr:exam`. Авто-перевод экзамен проверяет, ручная кнопка — нет.
- 🟡 `mentorship.py:110` — выговоры за срок считаются только `active=1`. Выговоры сами снимаются через `WARN_DAYS`
  (7 дн.), срок — тоже 7 дн. → выговор в начале срока к концу «сгорает», и **авто-перевод срабатывает**.
- 🟢 `mentorship.py:313` — «Продлить на 3 дня» считает от старого срока: если бот был выключен, новый срок уже в
  прошлом. Плюс не сбрасывает `reminded` — по продлению напоминаний нет.
- 🟢 `mentorship.py:104` — «сборов за срок» считает «Иду», а не реальную явку (`came` уже есть в сборах).
- 🟢 `staff.py:89` — один `_roster_task` на все семьи (Р1).
- 🟢 `context_menus.py:158` — `... and []`: мёртвый код (Р1).
- 🟢 `recruit.py` — «обзвон» засчитывается нажатием «Собеседование» на карточке, даже если разговора не было: при
  оплате за обзвон это легко накрутить.
**Идеи:**
- Объединить «📋 Досье» и «🛠 Управление» в одну карточку человека с кнопками: ранг · должность · выговор · штраф ·
  ЧС · наставник. Сейчас это два пункта меню с разными данными.
- Наставник ушёл с сервера или в отпуск → бот сам переназначает новичка (`pick_mentor`) и пишет в ветку.
- Контроль ника: бот знает ник и Static из анкеты — предлагать готовый ник по шаблону одной кнопкой
  «Поставить „Ivan Ivanov [123456]“» вместо «впиши сам».
- Оплату рекрутёрам за обзвон считать только за реальный перенос в комнату собеседования (`interviews.move`),
  а нажатие кнопки — как «взял в работу».

### 3. Экономика (`treasury`)
**Статус:** доступ только `TREASURY`, всё по `guild_id`, расход в минус — с подтверждением, выплаты по ставкам — с
предупреждением о повторе. Хорошо.
**Баги:**
- 🟢 `treasury.py:59-60` — сумма без суффикса с точкой: «1.5» → **15** (точки считаются разделителями разрядов).
  Для «1.500.000» верно, для «1.5» — нет. Однозначный случай (одна группа < 3 цифр после точки) — отклонять.
- 🟢 Речь `salary_ranks` не предупреждает «по ставкам уже платили N дней назад» (слэш — предупреждает).
- 🟢 Казначей может провести выплату **себе** или отметить **свой** штраф оплаченным — видно только в журнале.
**Идеи:**
- 🟡 **Должникам по взносу нет напоминаний** (есть только по штрафам). Добавить ЛС за 2 дня до конца периода тем,
  кто не сдал, — тот же цикл `remind_loop`.
- Кнопка участника «💰 Я сдал взнос» → заявка казначею с кнопками «Подтвердить/Нет» (сейчас взнос отмечает только казна).
- Операции «себе» (выплата себе, свой штраф) — только с подтверждением другого человека из `TREASURY`.
- Связать с автопарком: ремонт машины → расход казны с пометкой машины.

### 4. Модерация и защита (`moderation`, `security`, `blacklist`)
**Статус:** защита после ревизии 1 — по серверам, рейд сам выключается. Правила (инвайты/скам/реальные деньги) работают без ИИ.
**Баги:**
- 🟡 `moderation.py:44-65` — кнопки под флагом («Удалить + выговор», «Мут 30 мин») проверяют только роль
  (`LEAD + hr_head`), **без иерархии**: нач. кадров даёт выговор члену совета по его сообщению. `/выговор` это запрещает.
- 🟡 `moderation.py:166-181` — один буфер ИИ-модерации на всех, за 3 мин — одна семья, переполнение — потеря. (Р1)
- 🟡 `botcore.py:482` — ЧС альянса применяется к семьям, которые не в альянсе. (Р1)
- 🟢 `context_menus.py:267` — «🛡 Пожаловаться» без кулдауна: гость может завалить очередь модерации.
**Идеи:**
- Лестница наказаний — настройкой семьи: «3 выговора → кнопка „Исключить“ прямо в сообщении совету» вместо текста.
- Свести «антиспам» (security) и «правила» (moderation) в один модуль в `/настройки` — сейчас антиспам живёт в
  «Модерации», а защита от рейда/нюка вообще не отключается.

### 5. Дипломатия и альянс (`diplomacy`, `alliance`)
**Статус:** переговорные с протоколом и ИИ-резюме, доска отношений, договоры с истечением, совет альянса с голосованием.
**Баги:**
- 🟡 `alliance.py` — для подключённых семей с полным ботом используется ветка «чужой сервер» (`is_home` вместо
  `is_family`: строки 174, 193, 225, 240, 255, 267, 481). (Р1)
- 🟢 `diplomacy.py:271` — подвал договора `config.FOOTER` без `brand()`: у других семей там «Семья Ульяновы».
- 🟢 Переговорную может открыть кто угодно (гость), после закрытия — сразу следующую: кулдауна нет.
**Идеи:**
- Связать доску отношений с альянсом: семьи альянса — автоматически «🤝 Союз», выход/исключение — снимает.
- Автодополнение названий семей в `/отношения` и `/договор` (из доски + альянса) — меньше опечаток и дублей.
- Напоминание дипломатам за 3 дня до истечения договора.

### 7. Голос (`jarvis`, `music`, `voice_rooms`)
**Статус:** гонки плеера и автоплей исправлены, gTTS с таймаутом, защита от зависания объявлений.
**Баги:**
- 🟡 `jarvis.py:203-213` — слушатель декодирует и отправляет в Whisper речь **всех** семьи/друзей в канале
  (документация кога говорит обратное: «только тех, у кого есть право»). Итог: 5 болтающих людей выбивают лимит
  18/мин за минуту — команды хозяина не распознаются; разговоры уходят в Groq без ведома говорящих.
- 🟡 `requirements.txt` — `edge-tts>=6.1`, лаунчер обновляет пакеты только при изменении файла → вероятная причина
  «Нейроголоса не отвечают». (Р1)
- 🟢 `music.py:724` — ключ кэша TTS `hash()` меняется при каждом запуске. (Р1)
- 🟢 `voice_rooms.py` — хозяин комнаты может «выгнать» Главу из своей комнаты и запретить вход (это по смыслу
  нормально, но Глава не может себе вернуть доступ без админки).
**Идеи:**
- Джарвис слушает только хозяина и тех, у кого есть права помощника; остальных — только в режиме «поболтать»
  (бот сам зашёл проведать). Пока слушает — в чате канала одно сообщение «🎙 Швейцар слушает команды».
- Одно голосовое соединение на сервер (Music + Jarvis + объявления): вынести «кто сейчас владеет войсом» в одно
  место (`Music.voice_owner`) — сейчас это `hold` + `locks` + `asking` + `starting` в трёх когах.

## Коллизии мультисемейности

Всё, что ниже, — состояние или настройка «одна на всех», хотя должна быть на сервер.

1. 🟡 `activity` — `bot.voice_sessions[user_id]`: время войса засчитывается не той семье (Р1).
2. 🟡 `moderation` — один буфер ИИ-модерации (Р1).
3. 🟡 `staff` — один `_roster_task` (Р1).
4. 🟡 `streams` — `live`/`end_tasks`/`golive` по `user_id`; эфиры работают только на `GUILD_ID`.
5. 🟡 `alliance` — подключённая семья с ботом проходит как «чужой сервер» (Р1); ЧС альянса — всем семьям (Р1).
6. 🟢 `persona` — паузы «проведать»/«поприветствовать» общие (Р1).
7. 🟢 `applications` — сессия экзамена по `user_id` (Р1).
8. 🟢 `music` — голос TTS `tts:voice` общий на всех.
9. 🟢 Константы из окружения, одни на всех: `WARN_DAYS`, `DIGEST_DAYS`, `EXAM_*`, `MARKET_DAYS`, порог выговоров «3»,
   часовой пояс. Тексты семьи (`RULES_TEXT`, `WELCOME_TEXT`, чек-лист наставника, ситуационные вопросы) не
   редактируются через Discord.
10. 🟢 Картинки (`core/images.py`) и визитка — с названием и сервером домашней семьи.
11. 🟢 `server_setup` — сборка на подключённом сервере меняет порядок всех ролей и общие настройки сервера.

**Что проверено и в порядке:** все таблицы с данными семей имеют `guild_id`; все выборки по номеру, который вводит
человек (штраф, договор, машина, объявление, запланированное), фильтруются по серверу; ключи `role:`/`ch:`/`panel:`
живут в `guild_settings`; глобальные ключи `settings` — только служебные (`home_guild`, `hub:*`, `whisper:*`,
`tts:*`, `update:*`, `dev:*`, `alliance_charter`, `bot_avatar_set`); дублей слэш-команд нет; порядок `EXTENSIONS`
не важен (коги ищут друг друга через `get_cog` в момент вызова).

## Где фичи мешают друг другу и что можно объединить

- **Два разборщика времени** (`automation.parse_when` и `gatherings.parse_when`) понимают разные фразы → один общий.
- **Два разборщика сумм** (`market.parse_price` и `treasury.parse_amount`), разные валюты («₽» и «вирт») → один.
- **Напоминания помощника** живут в памяти, а рядом есть таблица отложенных `scheduled` → перенести туда.
- **Явка на сборы** считается, но не используется ни в сроке новичка, ни в зарплатах → одна метрика.
- **Досье и Управление** в контекстном меню — две карточки одного человека → одна.
- **ЧС семьи и ЧС альянса** проверяются одной функцией без учёта членства в альянсе → флаг «семья в альянсе».
- **Доска отношений и альянс** не знают друг о друге → союзники по альянсу = «Союз» на доске.
- **`/юрист` и `/спросить`** — одна и та же команда → оставить одну.
- **Джарвис, музыка, объявления, «спроси в войсе», «проведать»** делят одно голосовое соединение через четыре разных
  флага → один «владелец войса».
- **Еженедельный отчёт** и **сводка Главе** пересекаются → одна «сводка недели».
