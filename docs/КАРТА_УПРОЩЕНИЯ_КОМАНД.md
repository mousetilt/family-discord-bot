# Карта упрощения команд — план рефакторинга UX

Сейчас: **114 команд в 17 группах** — невозможно запомнить.
Цель: семья ничего не учит. Три способа сделать что угодно + мастер настройки + скрыть лишнее.

## Легенда назначений
- 🗣 **Речь** — просто написать/сказать боту, ИИ выполнит. Команда не нужна (многое уже работает).
- 🔘 **Кнопка** — действие на панели (жмёшь, не печатаешь). Будущая морда сайта — это же.
- ⌨️ **Команда** — остаётся слэш-командой (редкая, но удобнее так; видят только кому нужно).
- 🧙 **Мастер** — уходит в пошаговый `/настройка`.
- 🙈 **Скрыто** — служебное/разовое, видно только админу/владельцу (через права Discord).

## Итог — что человек видит, набрав `/`
| Кто | Команды, которые видит |
|-----|------------------------|
| **Участник** | `/помощь` · `/музыка` · `/рынок` · (и может просто писать боту) |
| **Руководство** | то же + `/настройка` · `/панель` |
| **Владелец/служебное** | + `/обновить` `/перезапуск` `/статус` (скрыты от остальных) |

Всё остальное — речью или кнопками на панелях.

## Новые панели (кнопки вместо команд)

**🛡 Панель руководства** (`/панель`, или закреплена):
Заявки · Должности и выговоры · Активность и сводка · Модерация · Дипломатия · Альянс · База знаний · Настройка

**👤 Панель участника** (закреплена в приветственном канале):
Отпуск · Моё досье · Профиль · Моя комната · Рынок · Стрим · Бусты

Нажатие открывает под-меню с кнопками — ни одной команды помнить не надо.

## Полная карта (по областям)

### ⚙️ Настройка и подключение → 🧙 Мастер
| Команда | Куда | Примечание |
|---|---|---|
| `/настройка` | 🧙 это сам мастер | пошагово: семья → роли → каналы → модули → ИИ → применить |
| `/семья роли` | 🧙 шаг «Роли» | |
| `/семья профиль` | 🧙 шаг «Семья» | |
| `/семья подключить` / `отключить` | ⌨️ владелец (редко) | можно и из мастера |
| `/настройки` (модули) | 🧙 шаг «Модули» | |
| `/ии ключ` / `статус` / `удалить` | 🧙 шаг «ИИ» + статус в `/помощь` | ключ — в модалку |
| `/права` (проверка доступа) | 🙈 внутрь мастера (аудит) | |

### 🎵 Музыка → 🗣 Речь (+ `/музыка` остаётся)
`играть, пауза, скип, стоп, громкость, очередь, перемешать, повтор, радио` → «включи …», «погромче», «дальше», «стоп». Группа `/музыка` остаётся как ярлык.

### 🛒 Рынок → 🗣 Речь (+ `/рынок` остаётся)
`продать, цена, поиск, мои` → «добавь на рынок …», «сколько стоит …».

### 🎖 Должности, ранги, выговоры → 🗣 Речь + 🔘 Панель
| Команда | Куда |
|---|---|
| `должность`, `ранг` | 🗣 «назначь Петю рекрутёром» / 🔘 Должности |
| `выговор`, `выговоры`, `снять-выговор` | 🗣 «выговор Пете за …» / 🔘 Выговоры |
| `мут`, `выгнать`, `исключить` | 🗣 + 🔘 Модерация (с подтверждением) |

### 📋 Заявки, обучение, экзамен → 🔘 Панель
| Команда | Куда |
|---|---|
| `заявки`, `обращения`, `список` (новички), `сводка` | 🔘 Заявки |
| `экзамен тренировка` | 🔘 Участник (кнопка «Пройти тест») |
| `экзамен вопросы/добавить/удалить/сгенерировать` | 🙈 руководство, внутри панели Заявки |
| `наставник назначить/рейтинг/список` | 🔘 Заявки / Наставничество |

### 📊 Активность → 🗣 Речь + 🔘 Панель
`отчёт, топ, неактив, сводка, сбор` → «кто неактив?», «сводка», «объяви сбор» / 🔘 Активность.
`отпуск, вернулся` → 🗣 «ухожу в отпуск» / 🔘 Участник.

### 🧠 Швейцар о людях (персона) → 🗣 Речь
`досье, забудь_меня, любимчики, прозвище` → «что ты обо мне помнишь», «забудь меня», «меня зовут Толик».

### 🎙 Голос → 🗣 Речь
`джарвис` → «зайди в войс и слушай». `голос` → 🧙 настройки/панель. `джарвис-статус` → 🙈 служебное.

### ⚖️ Юрист и база знаний → 🗣 Речь + 🔘 Панель
`юрист, спросить, найти` → 🗣 «спроси юриста …», «найди в правилах …».
`база ссылка/текст/файл/удалить/обновить/правила-проекта`, `список` → 🔘 панель «База знаний» (руководство).

### 🤝 Дипломатия и отношения → 🔘 Панель
`отношения установить/удалить/список`, `договор заключить/расторгнуть/список`, `переговоры пригласить/запросить` → 🔘 Дипломатия. Часть — 🗣.

### 🏰 Альянс → 🔘 Панель + 🙈 разовое
`альянс состав/устав/голосование/летопись/тревога/подключить/выйти` → 🔘 Альянс.
`альянс создать/штаб/пригласить` → 🙈 владелец, разово (в мастере альянса).
`чс (альянс и семья) добавить/убрать/проверить/список` → 🔘 ЧС + 🗣 «пробей Петю по ЧС».

### 🎤 Комнаты, стримы, бусты, летопись, пиар → 🔘 Панель участника + 🗣
| Команда | Куда |
|---|---|
| `комната открыть/закрыть/имя/лимит/передать` | 🗣 «открой комнату» / 🔘 Участник |
| `эфир, эфиры` | 🗣 + авто-роль «Стримит» |
| `буст роль/прогресс` | 🔘 Участник |
| `летопись запись/глава/летопись` | 🗣 «запиши в летопись …» / 🔘 |
| `визитка`, `профиль` (карточка) | 🔘 Участник / Пиар |

### 🛡 Защита, баннер → 🔘 Панель + авто
`защита статус/рейд` → 🔘 Защита (в основном работает само). `баннер, новость` → 🗣 / 🔘 руководство.

### 🔧 Служебное → 🙈 Скрыто (только админ/владелец)
`настройка-статус (бота), перезапуск, обновить, модуль, ошибки, копия` → видно только админу. `статус` бота также в `/помощь`.

## Порядок внедрения (ничего не ломая)
1. **`/помощь`** — интерактивная «что я умею» (сразу снимает нагрузку «что вводить»).
2. **`/настройка`-мастер** — съедает все настроечные команды.
3. **Панели** (руководства и участника) — переносим действия на кнопки; старые команды пока живут параллельно.
4. **Расширить речь** — дотянуть ИИ-действия до ежедневных задач руководства.
5. **Скрыть/ограничить** лишнее через права Discord; разовое — в мастер.
6. Позже — **сайт** как морда панелей.

На каждом шаге бот остаётся рабочим: команды убираем только после того, как их заменили кнопка/речь.
