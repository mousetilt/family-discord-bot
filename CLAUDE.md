# CLAUDE.md — память проекта «Ульяновский Швейцар»

Этот файл читается Claude Code автоматически. Здесь — весь контекст: что за проект, правила, архитектура, как деплоить, что сделано и что в планах.

## Что это
Бесплатный самохостируемый Discord-бот для RP-семьи **«Ульяновы»** (игра «Россия Онлайн», сервер «Арбатский»).
Хостинг: **bot-hosting.net** (бесплатный тариф, его надо продлевать каждые ~4 дня вручную).
Владелец: Никита (GitHub `mousetilt`, Discord-семья «Ульяновы»). Общение всегда **на русском**.

## 🔒 Железные правила (не нарушать)
1. **ТОЛЬКО бесплатное.** ИИ — Groq (`gpt-oss`) и Google Gemini (оба бесплатные ключи). TTS — Microsoft `edge-tts` + `gTTS` фолбэк. Распознавание — Groq Whisper. Никаких платных сервисов по умолчанию (OpenAI обсуждали — платно, максимум как 3-й резерв).
2. **Владелец/семья не должны лезть в код ВООБЩЕ.** Любая новая настройка — через Discord-команды (модалки для секретов), не через правку файлов. Это продуктовый принцип, цель — «пригласил бота, и он работает».
3. **Безопасность.** Никогда не реализовывать сбор паролей/почт/токенов, фишинг, скрытое сканирование дисков и т.п. (была попытка переименовать вредоносный .bat «под семью» — отказано). Панель управления (`maintenance.py`) НЕ выполняет произвольный код — только фиксированные действия.

## Архитектура
- `bot.py` — точка входа.
- `core/botcore.py` — `FamilyBot` (наследник commands.Bot). Загружает коги из `config.EXTENSIONS`. Модель: **один «домашний» сервер** (полный функционал, `bot.home_guilds`) + **альянс-сервера** (только ког `alliance`). События с неродных серверов роутятся только в Alliance.
- `core/config.py` — конфиг. Секреты из окружения: `DISCORD_TOKEN`, `GROQ_API_KEY`, `GEMINI_API_KEY`, `AI_PROVIDER` (сейчас `gemini`), `GUILD_ID`. Хардкод семьи/структуры тоже тут (это блокер мультисемейности, см. планы).
- `core/db.py` — sqlite, один коннект, схема v2 (`PRAGMA user_version=2`). **Все таблицы семьи с `guild_id`** — в каждом запросе фильтровать по серверу. Настройки сервера (роли `role:*`, каналы `ch:*`, панели `panel:*`, прозвища `alias:*`…) — в `guild_settings`, доступ `db.gget(guild, key)` / `db.gset(guild, key, value)` (guild может быть Guild/Member/int). Глобальное — `db.get/set` в `settings`: только `home_guild`, `hub:*`, `whisper:*`, `tts:*`, `alliance_charter`, `bot_avatar_set` (список в `GLOBAL_KEYS/GLOBAL_PREFIXES`). Старая база мигрирует сама при старте (копия `*.bak-v1`). Общие для всех семей документы базы знаний — `kb_docs.guild_id=0` (правила проекта/ООС). Выборки по уникальному id записи/сообщения/канала (кнопки бота) можно без `guild_id`.
- `core/ai.py` — ИИ с фолбэком: цепочка моделей провайдера + резервный провайдер; кулдаун на модель при лимите (`cool`), пометка мёртвых (`dead`). `ask()`/`ask_json()`.
- `cogs/` — фичи (см. ниже).

## Ключевые коги
- `assistant.py` (самый большой) — ИИ-чат и ДЕЙСТВИЯ: бот отвечает в чате и выполняет команды (музыка, ЛС, напоминания, законы, рынок, войс и т.д.) через JSON-actions от ИИ. `USERS` — привилегированные роли. `SYSTEM`/`SYSTEM_LITE` — промпты.
- `persona.py` — характер: досье на людей (−100..+100), злопамятный (отношение само не растёт), настроение по времени. Проведывает одиноких в войсе (с 08:00 до 02:00 МСК), встречает входящих. `/досье`, `/забудь_меня`, `/любимчики`.
- `jarvis.py` — голос: слушает войс, распознаёт через Whisper (лимит: 1800/сутки + 18/мин), выполняет голосовые команды. `say()` — озвучка.
- `music.py` — музыка + TTS (`announce()` сам заходит в войс, говорит, выходит). Голос `ru-RU-DmitryNeural`.
- `moderation.py` — ИИ-модерация (пакетами, на младшей модели).
- `maintenance.py` 🆕 — панель владельца: `/статус`, `/перезапуск` (через `os.execv`), `/обновить` (git pull + рестарт), `/модуль <имя>` (reload). Только Глава/зам.
- Прочее: `applications` (заявки), `diplomacy`, `alliance`, `market`, `mentorship`, `interviews`, `promo`, `boosts`, `streams`, `appeals`, `server_setup`, `daily`, `lawyer` (законы РО), `context_menus`.

## Деплой
- Хостинг bot-hosting.net: файлы в `/home/container`, секреты — во вкладке «Окружение» (НЕ в .git). Запуск: `pip install -r requirements.txt && python3 -u bot.py`.
- **Через GitHub:** правим код → `git push` → в Discord `/обновить` (бот делает `git fetch`, показывает список коммитов и перезапускается через `launcher.py`).
- **`launcher.py`** — стартовый файл на хосте (`STARTUP_FILE=launcher.py` в «Конфигурации запуска»; саму команду запуска хоста не трогаем). На каждом старте: есть git → `fetch` + `reset --hard origin/main` (при первом запуске сам делает `git init` в папке), нет git → качает zip с codeload.github.com. Игнорируемые файлы (`*.db`, `.env`, `.local`) не трогает. Если изменился `requirements.txt` — ставит зависимости. Любая ошибка → стартует на текущем коде. `start.sh` — старый вариант, не используется.
- Git на этом ПК: `C:\Program Files\Git\cmd\git.exe` (не в PATH у сессии Claude). Авторизация GitHub — через Git Credential Manager, уже выполнена.
- `.gitignore` исключает `.env`, `*.db`, логи, кэш — секреты в репозиторий не попадают. Репозиторий: `github.com/mousetilt/family-discord-bot` (public).
- Тест перед деплоем: загрузить все коги на оффлайн-боте (`FamilyBot(presences=False)` + `load_extension` в цикле) — должно быть без ошибок.

2. **Мультисемейность — этап 1:** ✅ сделано.

   - Маршрутизация: `bot.is_home(g)` — ТОЛЬКО главный сервер (основатель альянса, `/перезапуск`, `/обновить`, `/ошибки`, полная `/копия`). `bot.is_family(g)` — любой сервер семьи (домашний + подключённые, `bot.families`). `bot.home_guilds` — ВСЕ серверы семей (по ним ходят фоновые циклы). На серверах без семьи — только `/альянс` и `/семья`.
   - `cogs/families.py`: `/семья подключить` (владелец сервера) → `/семья профиль` (модалка) → `/настройка`. `/семья отключить` — данные сохраняются.
   - Бэкап чужой семье — только её данные (`daily.strip_foreign`).
   - Хвосты: паспорт/визитка (`core/images.py`) рисуют config.FAMILY/GAME_SERVER; промпт модерации не брендирован; `tts:voice` общий; эфиры (`streams`) работают только на `GUILD_ID`; ИИ-квота общая на всех (этап 3 — свои ключи).
3. **`/ии` и `/настройки`** ✅ (`cogs/control.py`).
   - ИИ всегда через `bot.ai_for(guild)` (НЕ `bot.ai` — это только ключи хоста для домашнего сервера). У подключённых семей ИИ работает ТОЛЬКО на их ключах (`guild_settings` `ai:groq`/`ai:gemini`, вводятся модалкой `/ии ключ`, проверяются `AI.probe`); без ключа — выключен (решение владельца: лимит хоста не делим). Квота `ai_usage` — по серверу (`день:guild_id`). Whisper (голос) — тоже ключ Groq семьи (`Jarvis.whisper_key`).
   - Ключи семей — секрет: не показывать (только `mask`), не логировать, вырезаются из полной копии базы домашнему серверу.
   - Модули: `bot.feature(guild, key)`, список в `core/family.FEATURES`, хранение `feat:key` (по умолчанию вкл). Новую отключаемую фичу — добавить в FEATURES и проверить в коде.

5. **Аудит коллизий** (роль бота низко, нет прав/интентов, дубли) + интерактивные правки.
