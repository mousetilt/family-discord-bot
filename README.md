# 🏛 Бот семьи Ульяновы · Россия Онлайн

## Быстрый старт (на своём ПК)
1. **Закрой окно старого бота**, если оно открыто.
2. Запусти `start.bat` — он сам поставит Python (если нет), библиотеки и запустит бота.
3. В Discord напиши **`/настройка`** — бот достроит сервер: новые роли и каналы, порядок ролей, герб на иконке, панели.
4. Для ИИ-юриста загрузи правила проекта с форума: **`/база правила-проекта`**.
5. Законы сервера (Конституция, УК, АК…) добавь ссылками на темы форума: **`/база ссылка`**.

Файлы `.env` и `family.db` не трогай — там твои настройки и вся база семьи.

## Бесплатный ИИ (по желанию)
Без ключа работает всё, кроме ИИ-функций. Чтобы включить ИИ бесплатно — вставь в `.env` один ключ:
- **Groq**: console.groq.com → API Keys → Create → `GROQ_API_KEY=...`
- **Gemini**: aistudio.google.com → Get API key → `GEMINI_API_KEY=...`
- **Claude (платно, по желанию)**: console.anthropic.com → API Keys. Ключ кладётся во вкладку «Окружение» хостинга
  как `ANTHROPIC_API_KEY` (в git НЕ коммитится) или семьёй через `/ии ключ`. Основным становится только по выбору
  (`/ии основной`); кончился лимит/деньги — бот сам откатывается на Gemini/Groq.

ИИ умеет: оценивать заявки, проверять чат (пачками раз в 3 минуты — экономит лимит), отвечать как юрист и составлять
иски/жалобы, писать недельные отчёты, главы летописи, резюме переговоров, придумывать вопросы для экзамена.

## 🌐 Хостинг 24/7 бесплатно — bot-hosting.net
1. Зарегистрируйся на **bot-hosting.net** → создай сервер **Python** (бесплатный план).
2. **Files** → загрузи `ulyanov-bot.zip` → ПКМ по архиву → **Unarchive**. Файлы должны лежать в корне
   (если появилась папка `ulyanov-bot` — зайди в неё, выдели всё и перенеси на уровень выше).
3. Там же **New File** → назови `.env` → вставь содержимое своего `.env` с ПК → Save.
   Чтобы не потерять базу — загрузи и `family.db` со своего ПК.
4. **Startup**: «App py file» = `bot.py`, «Requirements file» = `requirements.txt`.
5. **Console** → **Start**. Первый запуск ставит библиотеки 1–3 минуты.
6. ⚠️ Бесплатный план нужно **продлевать раз в 4 дня** кнопкой в панели. Не держи бота одновременно на ПК и на хостинге.

## Что умеет бот
| Модуль | Команды и как работает |
|---|---|
| 🏗 Сборка сервера | `/настройка` — 18 ролей, 11 категорий, 60 каналов, права, герб, баннер, панели |
| 📨 Заявки + экзамен | Кнопка → анкета → **тест 10 вопросов** (нужно 7) → 2 вопроса о себе → карточка рекрутерам с ИИ-оценкой. `/экзамен тренировка`, `/экзамен добавить`, `/экзамен сгенерировать` (ИИ по базе), `/заявки` |
| 🎓 Наставничество | Принятому новичку бот сам назначает наставника, создаёт личную ветку и чек-лист. Через 7 дней — кнопки «Перевести / Продлить / Исключить». `/наставник назначить / список / рейтинг` |
| ⛔ Чёрный список | `/чс добавить / убрать / проверить / список`. Проверка при заявке (Discord, Static ID, ник) и при входе на сервер |
| ⚖️ ИИ-юрист | `/юрист` (вопрос / разбор ситуации / составить документ), `/спросить`, канал #юрист, упоминание бота. База: `/база правила-проекта / ссылка / файл / текст / список / найти / обновить` |
| 📖 Летопись | Сама пишет: принятия, повышения, должности, союзы и войны, договоры, юбилеи, «нас уже 25». Раз в месяц — глава в летописном стиле. `/летопись запись / глава` |
| 🤝 Дипломатия | Кнопка «Запросить переговоры» → закрытый канал с дипломатами → протокол в архив. `/отношения установить`, `/договор заключить / расторгнуть / список`, `/переговоры пригласить` |
| 🛒 Рынок | `/продать` (с фото) → карточка с кнопками «Связаться» (приватная ветка сделки), «Продано», «Поднять». `/рынок поиск / мои`, `/цена` — статистика по сделкам |
| 🎶 Музыка | `/играть` (название или ссылка, плейлисты), `/радио` (9 станций или своя ссылка), панель ⏯ ⏭ ⏹ 🔁 🔀, `/музыка ...` |
| 🔊 Личные комнаты | «➕ Создать комнату» → своя комната. `/комната имя / лимит / закрыть / открыть / выгнать / передать` |
| 📣 Сборы | `/сбор` — кнопки «Иду / Возможно / Не смогу», лимит мест |
| 🎖 Кадры | `/ранг`, `/должность`, `/исключить`, `/выговор`, `/выговоры`, `/снять-выговор`, `/мут`, `/отпуск`, `/вернулся`, `/объявление`, авто-состав |
| 📊 Активность | `/профиль` — **семейный паспорт** картинкой, `/топ`, `/неактив`, `/отчёт`, недельный отчёт в воскресенье |
| 🛡 Модерация | Без ИИ: чужие инвайты, скам-ссылки, сделки за реальные деньги (предупреждает игрока о PermBan). С ИИ — проверка оскорблений, угроз и т.п. Всё — в #модерация с кнопками |

## Настройки
Всё меняется в `.env` (число вопросов экзамена, проходной балл, срок наставничества…) и в `core/config.py`
(названия каналов, тексты правил, радиостанции, чек-лист наставника).
